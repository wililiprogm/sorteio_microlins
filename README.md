# Sorteio: Fone de Ouvido + Curso Gratuito

## Como rodar localmente
1. pip install -r requirements.txt
2. python app.py
3. Acesse http://localhost:5000

## Antes de publicar (importante)
- Troque a senha do professor: variável de ambiente ADMIN_SENHA (padrão: microlins123)
- Troque a SECRET_KEY (variável de ambiente SECRET_KEY)

## Área do professor
Acesse /admin (pede senha) para ver os inscritos e sortear o vencedor.
